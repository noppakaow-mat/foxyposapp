React + Vite + Tailwind CSS

Foxyposapp เป็นระบบ POS (Point of Sale) สำหรับร้านอาหารบุฟเฟ่ต์ พัฒนาด้วย React, Vite และ Tailwind CSS

ระบบรองรับการจัดการโต๊ะ การเลือกแพ็กเกจบุฟเฟ่ต์ การสั่งอาหารผ่าน QR Code และการแสดงรายการสั่งซื้อแบบเรียลไทม์

พร้อมระบบจัดการออเดอร์สำหรับห้องครัวที่สามารถรับและติดตามรายการอาหารแบบเรียลไทม์ ช่วยเพิ่มความรวดเร็วและลดความผิดพลาดในการดำเนินงาน

ระบบสำหรับผู้จัดการ (Manager) รองรับการบริหารจัดการข้อมูลภายในร้าน เช่น การจัดการพนักงาน การจัดการสต็อกสินค้า การนำเข้าข้อมูลสินค้า และการดูข้อมูลสรุปผลการดำเนินงานของร้าน เพื่อช่วยให้สามารถควบคุมและวางแผนการบริหารร้านได้อย่างมีประสิทธิภาพ

ออกแบบให้รองรับการใช้งานหลากหลายอุปกรณ์ ทั้งคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน เพื่อให้เหมาะกับการใช้งานจริงภายในร้านอาหาร
